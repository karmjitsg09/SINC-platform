# SINC — FRONTEND TECHNOLOGY STACK MIGRATION ROLLBACK GUIDE
**Document ID**: `FRONTEND_STACK_MIGRATION_ROLLBACK_GUIDE`  
**Date**: October 2026  
**Status**: Authoritative File-Based Recovery Procedure (Zero-Git Mode)  

---

## 1. Overview & Rollback Principles

This rollback guide defines the strict, file-based recovery procedure to revert the SINC platform from the Next.js/Tailwind/TypeScript stack back to the original Vite-based React SPA **without using any Git commands** and **without deleting or overwriting any user modifications, tests, database schemas, or reports**.

### Absolute Constraints
1. **No Git Execution**: Do not run `git checkout`, `git reset`, `git revert`, `git stash`, or any other Git command.
2. **Preserve User Assets**: Local configuration, database migrations (`backend/schemas/`), reports, tests, and documentation must remain intact.
3. **Preserved Backup**: The entire pre-migration frontend code resides safely in the `frontend/` directory at the repository root.

## 2. Inventory of Migrated Files vs. Preserved Baseline

### Migrated Architecture (To Be Archived or Disabled)
- `src/` (Next.js source directory containing App Router routes `src/app/`, Zustand stores `src/stores/`, TypeScript types `src/types/`, etc.)
- `next.config.mjs`
- `tsconfig.json`
- `tailwind.config.ts`
- `postcss.config.mjs`
- `components.json`
- `.next/` (Generated Next.js build cache)
- `backend/socket-gateway/server.js` (Socket.IO gateway)

### Preserved Original Baseline (Source of Truth for Rollback)
- `frontend/` (Complete original Vite React SPA)
  - `frontend/index.html`
  - `frontend/vite.config.js`
  - `frontend/src/` (Original React components, contexts, hooks, services, styles)
  - `frontend/public/` (Original static assets and logo pieces)

## 3. Step-by-Step Rollback Execution Procedure

### Step 1: Terminate Active Background Processes
Stop any active Next.js or Socket.IO server processes running in the terminal:
- Next.js development server on port 3000
- Socket.IO gateway server on port 3001

### Step 2: Archive Next.js Configuration Files (Optional Non-Destructive Step)
Rename the Next.js configuration files to `.bak` rather than deleting them:
- `next.config.mjs` -> `next.config.mjs.bak`
- `tailwind.config.ts` -> `tailwind.config.ts.bak`
- `postcss.config.mjs` -> `postcss.config.mjs.bak`
- `components.json` -> `components.json.bak`

### Step 3: Restore Vite Scripts in Root `package.json`
In the root `package.json`, restore the `scripts` block to run Vite directly pointing to `frontend/`:

```json
{
  "name": "sinc-platform",
  "private": true,
  "version": "0.0.0",
  "type": "module",
  "scripts": {
    "dev": "vite frontend --port 3000",
    "build": "vite build frontend",
    "preview": "vite preview frontend --port 3000",
    "test": "node tests/e2e/verify_quick_2s_intro.cjs",
    "test:e2e": "node tests/e2e/verify_quick_2s_intro.cjs && node tests/e2e/verify_sidebar_bottom_nav_master.cjs",
    "test:perf": "node tests/performance/perf_remediation_runner.cjs"
  }
}
```

### Step 4: Revert `vercel.json` Configuration
In `vercel.json`, revert the framework setting from `nextjs` back to `vite`:

```json
{
  "framework": "vite",
  "buildCommand": "vite build frontend",
  "outputDirectory": "frontend/dist"
}
```

### Step 5: Clean Build Cache Artifacts
Delete temporary build cache directories that were generated by Next.js:
- Remove `.next/` directory (temporary build cache only; no source code).

## 4. Verification After Rollback

1. **Start the Vite Development Server**:
   ```powershell
   npm run dev
   ```
   Confirm that the terminal reports:
   ```
   VITE v5.4.1  ready in ... ms
   ➜  Local:   http://localhost:3000/
   ```

2. **Verify Public Route Loading**:
   Open `http://localhost:3000/login` in the browser or via Playwright:
   - Verify that the login view renders with the SINC transparent official logo.
   - Verify that all CSS styling and fonts load from `frontend/src/index.css`.

3. **Run Existing E2E Verification Suites**:
   ```powershell
   node tests/e2e/verify_auth_animation_lifecycle.cjs
   node tests/e2e/verify_quick_2s_intro.cjs
   node tests/e2e/verify_master_auth_experience.cjs
   ```
   All test suites are configured to test against `http://localhost:3000` and will execute against the restored Vite SPA.

This rollback procedure is 100% deterministic, relies purely on existing files on disk, does not execute Git commands, and preserves all user assets.
